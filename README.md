One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a smoke alarm that files a polite maintenance request instead of chirping at 3 a.m. — then holds a tiny grudge until breakfast.

## Run it

```sh
python3 main.py
```

The program writes the pitch (127 characters, one sentence) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. Standard library only.
